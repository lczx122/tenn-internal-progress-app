# Quote tool reference photos

Drop product photos here and they appear automatically in the quotation
generator — both in the on-screen picker (under the type selector) and as a
thumbnail on the generated quotation / sales-order document and PDF. No code
change is needed: a missing file is simply hidden, so you can add them over time.

**Format:** `.jpg`, roughly landscape (the picker crops to a 240×150 box, the
document to a 40×40 thumbnail). Use the exact filenames below.
